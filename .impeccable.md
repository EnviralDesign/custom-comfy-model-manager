## Design Context

### Users
ComfyUI power users managing model libraries across a fast local drive and larger lake storage. The primary job is quickly understanding file placement and moving, downloading, or removing models with minimal friction.

### Brand Personality
Technical, compact, and dependable. The interface should feel like an efficient local utility rather than a consumer product.

### Aesthetic Direction
Preserve the existing dark, information-dense interface and established controls. New features should fit the current visual language without redesigning surrounding surfaces.

### Design Principles
- Prefer narrow additions over broad visual changes.
- Keep frequent model-management actions immediate and discoverable.
- Preserve information density and existing interaction patterns.
- Make potentially destructive or stateful actions explicit.
- Maintain accessible labels and keyboard-visible control states.
